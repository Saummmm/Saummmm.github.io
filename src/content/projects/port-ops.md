---
title: Automating Port Operations with CV
year: 2024
area: CV
status: Complete
description: Explored and optimized CNN for the task of classifying different objects in a port.
modal:
  problem: Create a method for faster recognition of objets/vehicles coming into a port for the Port Authority.
  approach: Two different lightweight models were created with TensorFlow to create one custom model architecture and another with MobileNetV2. Implemented a pipeline to preprocess the data, including image augmentations to generalize ability to differentiate between different objects captured.
  results: High accuracy with transfer learning model achieved.
  limitations: Limited by number of images available for training the model. Imbalanced data along with many different labels to go through.
  future steps: Generate simulated samples with an oversampling techniques such as SMOTE.
